# 통통볼 챌린지

통통 튀는 공을 좌우로 움직여 **별을 모두 모으면 클리어**하는 웹 게임입니다.
스테이지는 10개이며 **1단계가 가장 쉽고 10단계가 가장 어렵습니다.**
빌드 과정 없이 HTML/CSS/JavaScript 만으로 동작하므로 GitHub Pages에 그대로 배포됩니다.

## 조작

| 키 | 동작 |
| --- | --- |
| ← → 또는 A D | 좌우 이동 |
| R | 다시하기 |
| Esc | 메뉴로 |
| 휴대폰 | 화면 아래 ◀ ▶ 버튼 |

## 블록 종류

| 블록 | 설명 |
| --- | --- |
| 파란 블록 | 밟으면 통통 튑니다 (한 번에 한 칸 높이까지 오를 수 있음) |
| 금 간 블록 | 한 번 밟으면 부서집니다 |
| 초록 점프 블록 | 아주 높이 튀어 오릅니다 |
| 주황 화살표 블록 | 벽에 닿을 때까지 화살표 방향으로 돌진합니다 |
| 가시 | 닿으면 실패 (바닥 가시 / 천장 가시) |

## 스테이지

| # | 이름 | 새로 등장하는 요소 |
| --- | --- | --- |
| 1 | 첫 걸음 | 이동, 별 모으기 |
| 2 | 구멍 조심 | 낭떠러지 |
| 3 | 계단 오르기 | 한 칸씩 오르기 |
| 4 | 뾰족뾰족 | 가시 |
| 5 | 점프 블록 | 점프 블록 |
| 6 | 무너지는 다리 | 부서지는 블록 |
| 7 | 질주 | 대시 블록 |
| 8 | 낮은 천장 | 낮은 천장 + 연속 가시 |
| 9 | 하늘 질주 | 점프 + 대시 조합 |
| 10 | 최종 시련 | 모든 요소 + 천장 가시 |

클리어 기록과 해금 상태는 브라우저(localStorage)에 저장됩니다.

## 스테이지 검증

`tools/solve.js` 는 게임과 **같은 물리 엔진(engine.js)** 으로 모든 입력 조합을 탐색해
각 스테이지를 실제로 깰 수 있는지 확인합니다. 스테이지를 고친 뒤에는 꼭 돌려 보세요.

```bash
node tools/solve.js      # 전체 검사
node tools/solve.js 7    # 7단계만 검사
```

## 스테이지 직접 만들기

`levels.js` 에서 20칸 × 13줄 문자열로 지도를 그립니다.

```
.  빈칸        #  블록          B  부서지는 블록   J  점프 블록
R  오른쪽 대시  L  왼쪽 대시     ^  바닥 가시       v  천장 가시
S  별          P  시작 위치
```

## 로컬에서 실행

`index.html` 을 더블클릭하거나, 정적 서버로 엽니다.

```bash
python3 -m http.server 8000   # http://localhost:8000
```

## 배포 (GitHub Pages)

`.github/workflows/pages.yml` 이 들어 있어서 `master` 브랜치에 푸시하면 자동으로 배포됩니다.

1. 저장소 **Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로 선택
2. `master` 브랜치에 푸시 (또는 Actions 탭에서 워크플로 수동 실행)
3. `https://<사용자명>.github.io/<저장소명>/` 에서 누구나 플레이

## 파일 구성

| 파일 | 내용 |
| --- | --- |
| `index.html` | 시작 페이지 (메뉴, 게임 화면) |
| `style.css` | 스타일 |
| `engine.js` | 물리 엔진 (게임과 검증기가 함께 사용) |
| `levels.js` | 10개 스테이지 지도 |
| `game.js` | 그리기, 입력, 소리, 기록 저장 |
| `tools/solve.js` | 스테이지 클리어 가능 여부 검증기 |
